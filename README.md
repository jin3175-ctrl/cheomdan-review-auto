# 체험단 후기 자동화 (수강생판)

폰 네이버 블로그 앱으로 **사진만 올려 임시저장** → 클로드 코드에 「방금 임시저장한 글로 체험단 후기 완성해줘」
→ 짧은 질문 → 글·사진이 채워진 **임시저장**. 발행은 직접.

- 🍎 맥: 에고라이트(lite.ego.app)가 사진 받기·임시저장을 합니다
- 🪟 윈도우: 어사이드(aside.com) + Aside CLI가 임시저장합니다

**받기**: 이 페이지의 `Code` → `Download ZIP`, 또는 [main.zip](../../archive/refs/heads/main.zip)
**설명서**: [사용법.md](사용법.md)
